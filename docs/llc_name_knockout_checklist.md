# SnowServ LLC — Name & Trademark Knockout Checklist

Run this **before** you file the Articles of Organization. Goal: confirm
**"SnowServ LLC"** is (a) available to register in NY and (b) not stepping on an
existing trademark. ~30–45 minutes. *Not legal advice — a knockout search reduces
risk but a clean result isn't a guarantee.*

---

## 1. New York name availability  (must pass to file)

- [ ] **Search the NY business database:** https://apps.dos.ny.gov/publicInquiry/
      → search **"SnowServ"** (and "Snow Serv", "SnowServe").
- [ ] Confirm **no existing NY entity** has the same or a confusingly similar
      name. NY requires your name be *distinguishable* from existing ones.
- [ ] **Name rules check:**
  - Must end in **"LLC"**, **"L.L.C."**, or "Limited Liability Company".
  - Avoid **restricted words** without approval (bank, insurance, trust,
      university, attorney, etc.) — none apply to SnowServ, so you're fine.
  - No wording implying a purpose the LLC isn't authorized for.
- [ ] *(Optional)* Reserve the name for 60 days (Application for Reservation of
      Name, ~$20) if you're not filing same-day. Usually unnecessary if you file
      right away.

**Result:** ☐ Available ☐ Taken → if taken, try "SnowServ Technologies LLC",
"SnowServ Marketplace LLC", or a holding-style name.

## 2. Federal trademark knockout  (should pass before you brand hard)

- [ ] **USPTO Trademark Search:** https://tmsearch.uspto.gov/
      → search **"SnowServ"**, then also **"Snow Serv"**, **"SnowServe"**, and
      the phonetic root **"snowserv*"** (wildcard).
- [ ] Look for **live** marks (not dead/abandoned) that are the same or similar
      **for related services**. The relevant classes for you:
  - **Class 37** — snow removal / property maintenance services (your core).
  - **Class 35** — online marketplace / connecting customers with providers.
  - **Class 42 / 9** — the software/app itself.
  A similar name in an *unrelated* field (e.g., a snowmobile part) is usually
  not a conflict; a similar name in **snow/home services** is a red flag.
- [ ] **Plain web + app-store search:** Google "SnowServ", search the Apple App
      Store and Google Play for "SnowServ" and close variants — catches
      unregistered ("common law") users you'd still want to avoid.
- [ ] **Domain/handles sanity check:** you own **snowserv.app** ✅. Optionally
      grab **@snowserv** on Instagram/X/Facebook and snowserv.com if available.

**Result:** ☐ Clear ☐ Possible conflict → if there's a live mark in Class 35/37,
pause and get a trademark attorney's read before committing the brand.

## 3. Go / no-go

- [ ] NY name **available** → proceed to file Articles ($200).
- [ ] Trademark **reasonably clear** → proceed with the brand; file your own
      trademark later (USPTO, ~$250–350/class) once revenue justifies it.
- [ ] Either one **fails** → adjust the name before filing (cheaper than
      rebranding after launch).
